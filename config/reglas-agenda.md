# Reglas de agenda - Versión consolidada

- Se permiten máximo 5 citas diarias.
- Las citas deben registrarse con al menos 24 horas de anticipación.
- Las citas deben registrarse en horarios disponibles.
- No se permiten reservas duplicadas.
- Cada paciente puede tener una sola cita activa.
- Cada cita debe tener fecha y hora.

## Criterio de resolución del conflicto

Se estableció un máximo de 5 citas diarias como límite definitivo, priorizando la regla más restrictiva de las dos versiones. Se conservaron las demás condiciones de ambas propuestas.
